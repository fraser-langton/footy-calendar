# Footy Calendar

<!-- impeccable:product-schema 1 -->

## Platform
web

## Purpose
A simple public AFL and AFLW subscription calendar. Everyone and both competitions included by default. Pick filters and receive a link to subscribe with a calendar app.

## Constraints
User chose a simple Vercel app, with code and fixture data on GitHub and schedule changes through pull requests. Avoid accounts, databases, complex frameworks and unnecessary services.
